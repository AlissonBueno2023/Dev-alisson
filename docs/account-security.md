# Password feature test cases

1. Enter a registered email and tap **Esqueci minha senha**.
2. Open the Supabase recovery email and confirm it returns to Sayure TV.
3. Set and confirm a new password.
4. Sign in with the new password.
5. From Account, open **Alterar senha**.
6. Verify an incorrect current password is rejected.
7. Verify the correct current password allows a new matching password.
